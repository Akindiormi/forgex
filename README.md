# ForgeX
Community app with daily quests, XP, levels, ranks and unlockable perks. No cash rewards: you earn status and access.
Flutter. Orange/black from the logo. Package: com.earnpalsolutions.earnpal
Local run: `flutter create --platforms=android --org com.earnpalsolutions --project-name earnpal .` then `flutter pub get && flutter run`.
Community posts and ranks are demo data for now; connect your backend later.
